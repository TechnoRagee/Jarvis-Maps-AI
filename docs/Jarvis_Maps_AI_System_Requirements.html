1. Overview & Deployment Philosophy

Jarvis Maps AI Studio is an enterprise geospatial automation platform engineered as a self-contained, frozen 64-bit Windows application.

The software has been packaged so that end users do not need to install Python, pip packages, virtual environments, or manual browser drivers. All GIS libraries (Shapely, PyProj, Fiona, OpenCV, Pandas) and Playwright automation hooks are embedded directly into the binary package.

Zero Development Prerequisites: End users only need a standard Windows 10/11 computer with an internet connection. The application boots right out of the extracted folder.

• Python Environment: NOT REQUIRED. Complete Python 3.11 runtime is embedded inside the package.
• Microsoft Office / Excel: NOT REQUIRED. Data is exported directly using native OpenPyXL and CSV formatters.

4. Network & Firewall Connectivity

Jarvis Maps AI interfaces with external geospatial endpoints for real-time map scraping, polygon synchronization, and geocoding:

Endpoint / Domain Protocol & Port Purpose in Application
maps.google.com HTTPS (Port 443) Interactive map loading, coordinate harvesting, place search
overpass-api.de HTTPS (Port 443) OpenStreetMap boundary polygons and administrative relations
nominatim.openstreetmap.org HTTPS (Port 443) Hierarchical geocoding (Localities, Suburbs, Sectors)
kml.google.com HTTPS (Port 443) KML/KMZ spatial schema validation
Corporate Proxy & Firewall Note: If operating behind an enterprise proxy, ensure outbound traffic on port 443 (HTTPS) is allowed to the domains above. No inbound ports or listener services are required.

5. Security, Permissions & Data Storage

🔒 User Privileges

• Standard User Rights: Administrator privileges are NOT required to run JarvisMapsAI.exe.
• The app can be extracted to C:\Users\<User>\Downloads, Desktop, or AppData without UAC elevation.

📁 Write Permissions

• The application directory requires local read/write permissions to store SQLite database records (jarvis_maps.db), Excel spreadsheets, and GeoTIFF files.
